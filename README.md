# Contact Book CLI — Python
A command-line contact management app built with Python.

##### What it does
- Add, view, search, update and delete contacts
- Saves contacts to a JSON file — data persists between runs
- Input validation for phone numbers and email addresses

##### Python concepts used
- Dictionaries and nested dictionaries
- JSON file I/O (json.load, json.dump)
- Functions and while loop menu
- String methods and input validation
